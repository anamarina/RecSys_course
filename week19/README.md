# Week 19 Grocery Recommendation Demo

Локальный демо-сервис для занятия про онлайн-рекомендации:

- сверху показывается бесконечная лента grocery-товаров;
- пользователь добавляет товары в корзину;
- снизу сервис сразу пересчитывает top-5 рекомендаций методом `EASE`;
- уже показанные товары не возвращаются в ленту;
- любую карточку можно скрыть вручную.

## Что внутри

- `app.py` — backend + HTTP server + обучение `EASE` на synthetic baskets.
- `static/` — фронтенд для демонстрации.
- `grocery_synthetic_dataset/` — синтетические корзины, каталог и PNG-картинки.

## Запуск

Из корня репозитория:

```bash
python3 week19/app.py
```

## Как устроены рекомендации

`EASE` обучается на матрице `basket x item`, где каждая синтетическая корзина считается пользователем.
Во время демо текущая корзина посетителя превращается в бинарный вектор, затем считаются scores
`cart_vector @ B`, после чего:

- уже лежащие в корзине товары исключаются;
- уже показанные и скрытые товары не рекомендуются повторно;
- если score-кандидаты закончились, список дозаполняется популярными товарами.
